# RaidTalk AutoClicker — Android Edition

Отдельный Android-клиент. Windows/Electron-версия не изменяется.

## Текущий этап: 0.1.0 — технический каркас
- Kotlin + Android WebView.
- RaidTalk открывается по HTTPS.
- Координаты и интервал сохраняются локально.
- AccessibilityService использует системные жесты.
- Защитное ограничение: нажатия отправляются только когда активным окном является само приложение RaidTalk AutoClicker.

## Ограничения Android
AccessibilityService выполняет касания по экрану, а не отправляет события в скрытую WebView. Поэтому эта версия не обещает клики по скрытым вкладкам, поверх других приложений или при выключенном экране. Для базовой проверки окно RaidTalk должно оставаться на переднем плане, а экран — включённым. Энергосбережение и ограничения производителя могут останавливать фоновые процессы.

## Сборка
Откройте папку android в Android Studio (JDK 17, Android SDK 35), дождитесь Gradle Sync и соберите:
Build → Build Bundle(s) / APK(s) → Build APK(s).

Выходной APK: android/app/build/outputs/apk/debug/app-debug.apk.
