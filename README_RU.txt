RAIDTALK AUTOCLICKER — Windows 10/11 x64

ЗАПУСК
1. Распакуйте архив целиком в новую папку.
2. Установите Node.js LTS с https://nodejs.org/en/download
3. Запустите START.bat. Первый запуск скачает Electron.
4. Следующие запуски — двойной щелчок по START.bat.

ИНТЕРФЕЙС
- Сверху расположены все 20 вкладок в один горизонтальный ряд.
- У каждой вкладки отдельный постоянный профиль Chromium (cookies/localStorage).
- Все вкладки открывают https://app.raidtalk.ru.
- Адресная строка меняет сайт только в выбранной вкладке.

ВЫБОР ТОЧКИ (PICK ON PAGE)
1. Выберите вкладку.
2. Нажмите «Pick on page — выбрать точку».
3. На сайте появится красный прицел.
4. Наведите его на нужное место и щёлкните один раз.
5. X/Y автоматически запишутся и сохранятся для этой вкладки.

АВТОКЛИКЕР
- Укажите интервал в миллисекундах (минимум 250).
- «Проверить клик» выполняет одно нажатие.
- «Старт» запускает кликер выбранной вкладки.
- «Старт всех» запускает кликеры на всех 20 вкладках RaidTalk.
- Каждый автоматический клик показывает жёлтую мигающую окружность.
- «Стоп» и «Стоп всех» останавливают автокликеры.

ВАЖНО
- Это исходный проект, не автономный EXE. Для первого запуска нужны Node.js LTS и интернет.
- Координаты считаются от левого верхнего угла видимой страницы.
- Автоматизация допустима только если это разрешено правилами RaidTalk.
- Приложение не обходит CAPTCHA, антибот-защиту или ограничения аккаунтов.
- Закрытие программы останавливает все автокликеры.


ИСПРАВЛЕНИЕ ФОНОВОГО АВТОКЛИКЕРА:
- Для фоновых WebContents отключено backgroundThrottling.
- Таймеры автокликера выполняются в основном процессе Electron.
- Убран принудительный focus() целевой вкладки перед каждым нажатием, чтобы она не перехватывала фокус.
- Клики направляются в конкретную вкладку по её WebContents ID, даже если выбрана другая вкладка или окно программы свёрнуто.
- При переходе компьютера в сон/выключении автоматические клики приостанавливаются.


АВТООБНОВЛЕНИЕ:
- Кнопка «Проверить обновления» находится по центру рядом с названием программы.
- Установленная версия автоматически проверяет GitHub Releases при запуске и каждые 6 часов.
- Для работы канала необходимо создать репозиторий vertuozi92/RaidTalk-AutoClicker и опубликовать первый релиз. Подробности — UPDATE_CHANNEL_SETUP_RU.txt.
