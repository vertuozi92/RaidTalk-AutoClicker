КАНАЛ ОБНОВЛЕНИЙ RAIDTALK AUTOCLICKER

В этой версии добавлен интерфейс проверки обновлений и интеграция electron-updater с GitHub Releases.

ВАЖНО: канал станет рабочим после создания отдельного публичного репозитория vertuozi92/RaidTalk-AutoClicker и публикации первого установщика в GitHub Releases. На момент подготовки этого архива репозиторий ещё не создан, поэтому первая проверка обновлений из установленной сборки пока не сможет найти релизы.

ПОРЯДОК ПУБЛИКАЦИИ НА WINDOWS:
1. Создать публичный GitHub-репозиторий с именем RaidTalk-AutoClicker (владелец vertuozi92).
2. Загрузить в него исходный проект.
3. На Windows выполнить npm install.
4. Для первой сборки выполнить npm run dist.
5. Для публикации релиза настроить GH_TOKEN с правом Contents: Read and write и выполнить npm run publish.
6. Следующие обновления выпускать с увеличением version в package.json и повторной публикацией.

Кнопка «Проверить обновления» расположена по центру рядом с названием. Программа также автоматически проверяет обновления при запуске и затем каждые 6 часов. Загруженное обновление устанавливается после нажатия кнопки установки либо при следующем штатном выходе из программы.

Настройки вкладок и профили Chromium хранятся отдельно от файлов приложения и не должны удаляться установщиком.
